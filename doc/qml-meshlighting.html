Detailed Description

Module for lighting a Node in a View3D scene. Implements three DirectionalLight's that change their axial rotation depending on the rotation of the orthographic camera. This ensures that the 3 sides visible to the user are well-lit, while the other sides remain shadowed to depict object depth.

Setting the color of a loaded object

To set the color of a loaded object, set target to the id of the Node object and set targetColor to the desired color of light.

MeshLighting {
    target: node
    targetColor: "cyan"
    camera: myCamera
}
